# 排口污染负荷离线复核台

澄川水务集团某污水厂排口的 **COD、氨氮、流量** 记录离线复核工具。断网环境可完整运行：
接入账与文件指纹、点位/设备实例、校准系数与状态有效期、片段编织与来源链、
自然日/月污染负荷与不确定范围、覆盖率与申报资格、迟到读数的锁定窗口复算候选。

本次新增 **短时高氨氮事件来源调查**：来源登记簿（支管接入位置、允许排放时段、雨量、
泵站切换、自报批次，全部带版本与可信等级）、水力候选生成器、证据组合器
（时间带相容性 + COD/氨氮/电导率/pH/流量特征 + 缺测惩罚）、调查处置板与可审计交付页。
两条发布路线（保守集合 / 可拒答排序）**只输出调查优先级，不输出责任结论**。

技术栈：**React 19 + TypeScript 5.9 + IndexedDB(idb) + WebWorker + Vite 7**。
所有重计算在 Worker 内完成，主线程只读写本地库与渲染；数据不出本机。

## 5. 计算口径（与引擎一致）

- 时间轴：`alignedAt = sampledAt + clockOffsetMs`，自然日按 Asia/Shanghai（UTC+8）。
- 片段边界：自然日端点、仪表实例/绑定交接、校准生效、状态切换、采样空档端点。
- 状态：仅 `OK` 可积分；`FLUSH/CALIB/BYPASS/FAULT` 整段排除并保留状态 ID。
- 采样空档：同一实例相邻有效读数间隔 > `nominal × 2.5`；空档自「上一读数 + 一个标称间隔」
  起算。段端最多保持一个标称间隔，不跨校准系数插值。
- 负荷：`∫ c(t)·q(t) dt / 3.6e6`（mg/L × m³/h × 秒 → kg）。
- 不确定范围：逐片段相对不确定度平方和开方 × `k`（默认 2）；重采样路线额外叠加
  梯形法解析误差界 `|c′q′|h³/6`。
- 覆盖/资格：覆盖率 = 有效积分秒 / 86,400；低于申报线 15pp 以上判不可申报。

### 事件调查口径（与 `src/investigate/` 一致）

- 事件窗口：取自本复核台氨氮阈值穿越区间；事件指纹 = 事件窗口均值 − 事件前 1 小时
  基线（隔 10 分钟），半宽按仪表相对不确定度合成（k=2）；电导率/pH 取自事件加密监测。
- 水力召回：排放窗口 = [事件起点 − 传播上限, 事件终点 − 传播下限]；泵站中途切换按
  排放时刻所处体制分别倒推并裁剪，无可行时刻的体制如实标注，不按单一体制收窄。
- 证据组合：时间带相容性为门槛（不计分）；特征维度按观测增量与登记包络的重叠比
  （占观测宽度）判定：≥0.8 相容 ×1.0、≥0.15 弱相容 ×0.5、<0.15 反证 ×−0.75；
  缺测只产生缺失惩罚（完整度 = 1 − Σ缺测权重）。
- 自报贡献乘可信系数（A=1.0 / B=0.8 / C=0.55）；自报否认是反证（×−0.75×可信系数）；
  雨量维度只对雨污合流溢流计分（≥2×阈值相容、≥阈值弱相容、<阈值反证）。
- 集合路线：只发布满足预先声明门槛的候选集合；同一自报批次的流量与自报维度不重复
  计独立支持数；暴雨期间无独立反证的候选必须保留并列。
- 排序路线：按 Σ贡献降序；前两名分差 <0.05 或首位完整度 <0.6 时输出「不可判定」；
  必须展示对自报更正（旧版本重放）与雨量误差界（±缩放）的敏感性。
- 版本纪律：自报更正按版本撤销旧批次与旧评分；拓扑修订不改写已关闭调查（关闭快照
  冻结）；交付内容哈希 = SHA-256（候选证据 + 门槛 + 登记簿版本），发布后不可改写，
  更正只能产生新版本并取代旧版本。
- 两条路线只输出调查优先级，不输出责任结论。

### 两条积分路线

| | 逐有效片段积分（默认） | 经误差界验证的重采样积分 |
| --- | --- | --- |
| 局部证据 | 每个片段保留读数/校准/状态/文件 | 保留边界，片段内网格化 |
| 窄事件 | 40 s 冲击边界精确到读数时刻 | 需斜率上界 + 细分，否则会漏检 |
| 汇总成本 | 片段与结点多，查询较重 | 网格单元轻，便于跨层聚合 |
| 证明责任 | 无需额外证明 | 必须证明负荷范围、峰值、阈值穿越不变 |

核验阈值（`src/domain/engine.ts`）：负荷相对偏差 ≤0.5%，1h 峰值窗口中心偏移
≤ max(30 s, 1 网格)，阈值穿越并集对称差 ≤2 s，网格细分后无未决单元。

## 6. 申报与迟到复算

1. 「覆盖与资格」出具申报 → 生成 `FILED` 版本；截止接收时刻默认取该点位当日数据集的
   最大 `receivedAt`（样例为 2026-11-19 07:20），并锁定来源窗口、
   来源读数 ID 快照与来源文件指纹。
2. 「复算候选」导入迟到补录 → 读取落在锁定窗口内且 `receivedAt > 截止` 的读数。
3. 生成候选：只把迟到读数并入重算，原申报版本**不做任何修改**（`declarationOverwritten: false`），
   候选保存 `baseline` / `recomputed` / `diff` 与受影响片段。
4. 人工填写复核附注并标记 `REVIEWED`；是否作为下一版申报依据由人工决定。

## 8. 已知边界

- 样例覆盖 2026-11-18 单日（基线）与 2026-11-20 12:00–18:00（暴雨日）；月度页会明确显示
  有数据天数与缺失天数，不补零。暴雨日只覆盖 6 小时，覆盖率自然偏低，属预期。
- 时钟校正量来自设备台账的固定值；时钟漂移本身未建模，但偏移不确定度计入区间说明。
- 流量与浓度读数均取自一个排口的同一时刻对齐序列；跨厂站对比仅做展示，不合并负荷。
- 事件指纹的电导率/pH 维度依赖事件期间的加密监测记录；无加密监测时按缺测处理。
- 来源登记包络为「排口等效增量」率定值，不替代溯源模型；候选评分只排调查优先级。
- 浏览器端到端冒烟（`scripts/browser-smoke.mjs`）需要本机 Chromium（playwright-core），
  不属于 `npm run verify` 的必需步骤；核心验证不依赖浏览器。
- 本工具不替代法定监测数据有效性判定与污染责任认定，只提供可追溯的复核证据、
  缺口量化与调查优先级。
